# Catalyst Crowd 

**A Community-Powered Crowdfunding Platform**

Catalyst Crowd is a web application that allows users to discover campaigns, create fundraising campaigns, and record simulated contributions. It uses Firebase for authentication and cloud data storage.

 **Live Website:** https://catalyst-crowd-ee987.web.app

##  Features

* **User Authentication:** Sign up and log in using email and password.
* **Explore Campaigns:** Browse, search, filter, and sort fundraising campaigns.
* **Create Campaigns:** Publish campaigns with details such as title, description, category, fundraising goal, deadline, and image.
* **Campaign Details:** View campaign information and fundraising progress.
* **Simulated Contributions:** Record contributions and track campaign progress without processing real payments.
* **Responsive Design:** Access the platform on desktops, tablets, and mobile devices.

##  Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Authentication:** Firebase Authentication
* **Database:** Cloud Firestore
* **Hosting:** Firebase Hosting
* **Version Control:** Git and GitHub

##  Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Manashwini-1903/Catalyst_Crowd.git
   ```
2. Open the project folder in VS Code.
3. Start the website using the Live Server extension.
4. Ensure the Firebase configuration and security rules are set up correctly for your Firebase project.

##  Note

This is an educational crowdfunding project. Contributions are simulated; no real money is transferred.
